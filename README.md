# Gravity Switch

Koule umí jedinou věc: padat. Ty jí říkáš kam. Dvacet místností, nekonečný běh, par za čistý průchod.

## Ovládání

- **Mezerník** nebo tlačítko přepne gravitaci: dolů → nahoru → doleva → doprava
- Šipka na tlačítku ukazuje, kam poletíš po dalším stisku
- Červená zóna je jáma. Méně stisků = čistší skóre

## Módy

- **20 místností** s par skóre a lokálními rekordy
- **Nekonečno** — procedurální místnosti, klesající rozpočet stisků, nejdelší série

## Vývoj

```bash
npm install
npm run dev
```

Čistý React + Canvas, bez herního enginu.
