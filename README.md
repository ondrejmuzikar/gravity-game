# Gravity Switch

Puzzle plošinovka: jediná akce, čtyři směry gravitace. Dostan kuličku z startu do cíle — červená zóna je propast. Méně přepnutí = lepší skóre.

## Ovládání

- **Mezerník** nebo tlačítko **Přepnout gravitaci**
- Cyklus: dolů → nahoru → doleva → doprava
- Tři levely rostoucí obtížnosti, restart a počítadlo přepnutí

## Vývoj

```bash
npm install
npm run dev
```

Produkční build:

```bash
npm run build
npm run preview
```

Čistý React + Canvas, bez herního enginu.
